# Testing

_Test strategy, test cases and results._

## Strategy

_What is tested, how (manual / automated), and with which tools._

- Automated: Vitest in both workspaces (decisions.md S0-4). Web tests run through `@angular/build:unit-test` with jsdom, so no browser is needed. Root `npm test` is the gate (D4).
- Manual: the validation steps of each slice in plan-v2.md, recorded below.

## Known issues

_Bugs found during testing and their current state._

- **npm 11 install-script warnings (S0, open, harmless so far):** `npm install` prints `install-scripts ... not yet covered by allowScripts` for esbuild, lmdb, msgpackr-extract and @parcel/watcher, and skips their scripts. Build, serve and tests still work (esbuild ships its binary as an optional dependency). In the README under Known limitations (S5). Same on the S5 fresh clone.
- **`ng serve` crashed in Vite's dependency optimizer (found in S3, fixed by decisions.md S3-6):** after the S2 lockfile change invalidated the prebundle cache, the dev server exited with `Could not resolve './identity' in ../../packages/shared/src/index.ts` (twice, deterministic). Cause: the extensionless re-exports added in S1; the optimizer resolves only `.mjs/.js/.cjs`. `ng build`, `ng test` and `ng serve --configuration production` (no prebundling) were not affected. After the fix: the dev server starts, `/alerts` and `/alerts/new` load, and the severity select shows the shared `SEVERITIES`. A fresh clone with `npm start` was probably broken from S1 until this fix. _Re-checked 2026-10-18 (S5-2): a fresh clone starts._
- **Switching Admin → user on `/admin` sends admin requests as the user (found in S5, open):** with the admin page open, choosing Alice in the switcher re-sends `GET /api/admin/deliveries`, `/sources` and `/channels` with `X-User-Id: alice` before the shell navigates to `/alerts`; the API returns 403 and the interceptor shows "Admins only.". The server check works as intended (A8); the extra requests and the message are a UI bug. Answers the first S4 review question. Not fixed in S5 (docs only); a fix needs its failing test first.
